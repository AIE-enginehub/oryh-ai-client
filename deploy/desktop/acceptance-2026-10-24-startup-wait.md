# 首次钥匙串迁移等待修复验收

实现提交：`7100de19c17595c3cfcfe01c0d329024aa9d3e6b`。

## 原因与修复

`@napi-rs/keyring` 的 `Entry.getPassword()` 是同步原生调用。旧实现即使声明为 async，等待 macOS 授权时仍阻塞整个 Harness Host，桌面壳无法取得启动语言设置，最终触发 HTTP headers timeout 并退出。

ORYH 外部连接插件改用只读迁移子进程执行这次读取。子进程使用同一个签名可执行文件，继承官方 Host 的 Node 运行环境；凭据通过私有 IPC 返回 Host，仍由 Harness credentials 服务原子保存。正常读取、刷新、新登录和注销继续使用 Harness 记录。没有改动上游检出、放宽系统授权或延长超时。

Host 生命周期结束会终止待授权子进程。拒绝授权、异常退出和格式不合法均返回固定错误，不输出原生诊断或凭据；同一连接的失败继续由迁移层在本次 Host 生命周期内锁存。
